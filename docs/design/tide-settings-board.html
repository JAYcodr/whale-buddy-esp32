高对比白纸确认卡：松手后识别文字直接印在纯白大卡上（不倒计时自动发）；撞上在跑会话直接给出排队（钴蓝）与打断（绯红）双色分流。

3. 「深海原版 ⇄ 深蓝潮汐」做成可切换主题：到底难不难？

读完 nva.cpp / theme.cpp / settings.h 后的真实结论：不难，无架构阻塞，不占双份 Flash。

① NVA 动画：已原生支持透明索引 0

nva.cpp:541 写像素前本来就判断 if (idx)，直接能压在钴海蓝和 fontNum92() 巨字时间前面！唯一细节是现有 .nva 边缘预乘了黑底——改 convert_pet.py 留 8 个半透边缘色槽做实时混合，一套 10.4MB 动画同时通吃深黑与潮汐。

② 字体与 NVS：现成直接复用

theme.cpp 的 drawText() 已是读帧缓冲实时 4-bpp alpha 混合，任意底色都无毛边；92px 大数字 fontNum92() 也已在固件里。settings.h 加一项 theme 进 kSettings[] 只要 5 行，支持免重启热切。

③ 真正的工作量在逐页排版分支

想做到不“换皮”，page_home / tokens / quota / approval / chat / settings / rank 7 个页面需要按主题走各自的布局（约 1–2 天代码 + tools/sim 像素基线验证），功耗方面建议默认仅亮屏用潮汐、进 AOD 自动切回纯黑表盘省电防烧屏。
