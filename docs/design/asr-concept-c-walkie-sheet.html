概念 全局随叫随到的模态对讲抽屉，而不是必须划 4 次才能到达的「语音页」。
内容组织 底层保留当前页面上下文（主屏 / 额度页）；浮层内仅分 对讲（频谱 + 转写 + 1 张简短答复卡 + PTT）与 收音自测（2×2 声学指标 + 3s 包络 + 采样回放）。
交互模型 按住即说、松开即发（支持物理 KEY1 与触屏 PTT 双触发）；答复播报后支持 4s 自动收起，不打断用户原本在看的数据。
视觉语法 底层页面降暗至 28% + 轻模糊退后，344px 浮层圆角卡片沿用 OLED 深蓝底与青/薄荷语义色，录音态青边呼吸、异常麦质珊瑚红告警。
