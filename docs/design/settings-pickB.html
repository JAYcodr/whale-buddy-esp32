真的可以点：点行展开、点选项生效、点开关切换、拖滑块调值、拖列表滚动。右侧细条是滚动位置。
设备一屏 = 8 行；这里能同时看到的行数取决于上面的缩放。

「一张从上到下的清单 —— 按你说话的顺序排，右边写着现在的值；点哪行，值就在那一行里展开。」

没有tab。4 个 40×34 的小按钮没了，换成 6 个组标题。
没有跳页。点开的值就在原地展开，不换屏、不整页重绘。
没有「完成返回」。左上箭头和 Key1 长按都能走。
没有说明文字。「到 90% 自动停充」这类灰字全删，值本身就是说明。
为什么是这 6 组
屏幕我嫌它太亮、太暗、关得太快
熄屏显示熄屏之后那块表盘，什么时候出来、要不要更护眼
声音我嫌它太吵，或者它不说话
电池我想让它撑久一点，或者别老充满
行为我想换个首页 / 省点电 / 让它自己动
设备我要重新连网，或者推倒重来

分组按「你什么时候会想到它」，不按功能模块。「熄屏」是屏幕什么时候灭；「熄屏显示」是一组独立的：什么时候开、多久切过去、亮度要不要保护。两组分开，不再套缩进。

03

交互与动效

10 条规则 · 7 条动效
点一行 = 就地展开行高从 48 变 92，下面长出选项条；同一时刻只开一行，点开另一行时上一行自动收起。
点选项 = 立即生效不等确认、不弹提示，选完自动收起。值写 NVS 后整行重绘一次（12ms），不整页闪。
点开关 = 直接切开关行不展开，点击即刻翻转；开关命中区是整行，不是那个 38×22 的小方块。
拖滑块 = 连续调亮度和音量展开后是一条滑轨，拖动实时改值、行右侧数字跟着变；松手不收起，点行标题才收。
滑块与滚动不打架手指落在滑轨上就先判方向：水平 → 调值，垂直 → 让列表滚。
上/下拖 = 滚动带惯性（复用榜单页的 fling），右侧细条显示位置。滚到底部不多余回弹。
危险动作要两次重新配网、恢复默认：第一次点变红「再点一次确认」，3 秒不点自动恢复，点别处也取消。
恢复默认的范围13 个设置项回出厂值（亮度 100%、音量 75%、AOD 仅插电…），不动配网信息和设备号。
返回有三条路左上箭头、Key1 短按回首页、Key1 长按再来一次。没有「完成返回」按钮。
热区行 48px（≈4.2mm，比现在的 40×34 tab 大一倍）；选项 36px 高。都 ≥ 现有最小热区。
动效 · 以及它在设备上做不做得起
行展开 160ms ease-out选项条从 0 长到 46，同时淡入并上移 5px。设备端 3 帧，做
选项选中 120ms底色扫过、按下时整块缩到 0.965。设备端 1–2 帧，做
开关 180ms 弹簧knob 带一点回弹（cubic-bezier .34,1.56,.64,1），底色同步。设备端 3 帧，做
滑块 拖动 / 松手拖动中只有 knob 放大 1.1 —— 整行不点亮、数值不闪，因为这是连续状态；松手那一帧数值才闪一次白光落下（340ms）。只重绘这一行，便宜
试听 1.4s按钮亮起 + 一圈波纹扩散。波纹要 12 帧，建议降级：亮 200ms + 图标闪两次就够了。
危险确认 420ms整行背景红闪一次，「再点一次」同时淡入。设备端 3 帧，做
滚动条 350ms滚动时亮到 100%，停手 900ms 淡到 50%。只改一条 2px 宽的条，几乎不要钱。
原则屏幕是 10–12ms 一帧推的。动效只在「状态变了」的时候跑，静止时一帧都不画 —— 否则电池先撑不住。
04

砍掉了什么

对照现状
删掉
  • 顶部 4 个 tab（基础 / 进阶 / 电源 / 显示）—— 40×34，比 44pt 还小
  • 底部 4 个重复的「完成返回」按钮
  • 进阶页的 MQTT Broker 只读块（详情页已有）
  • 电源页的电池状态只读块（详情页已有）
  • 每页 2–3 条灰色说明文字（「到 90% 自动停充 · 拔插后重充」这类）
  • 「进阶」这个分类名本身
合并 / 挪动
  • 息屏（进阶）+ AOD 三项（显示）→ 拆成「屏幕」和「熄屏显示」两组，不再套在一起
  • 音量（基础）+ 试听（底部按钮）→ 同一组，「试听」变成一行动作
  • 默认首页 + 功耗档 + AI 编排 → 新分组「行为」
  • 重新配网（进阶底部）→ 底部「设备」组
  • 只读状态（WiFi / MQTT / 电池 / 版本）→ 详情页，设置页只留一行版本小字
新增
  • 右侧 2px 滚动位置条
  • 「恢复默认」动作（现状没有）
  • 行级二次确认（现状只有配网有）

06

还需要你拍板的 9 件事

细节
01组名　屏幕 / 熄屏显示 / 声音 / 电池 / 行为 / 设备 —— 有没有哪个词你不顺眼？「行为」是最弱的一个，备选：动作、系统、玩。
02只读信息确认删　WiFi / MQTT / 电池状态全挪去详情页，设置页只留一行版本号。详情页那屏能不能装下，我会先量过再动。
03「试听语音」留不留　留就是一行动作（点了响一声），删就是少一行、少一个入口。
04恢复默认的范围　我按「13 项设置回出厂、配网与设备号不动」写。要不要连 AOD 一起回？
05滑块的范围　亮度 20–100%（20 就是现在最暗那档，再暗真看不见）、音量 0–100%、步进 5%。要 1% 的细度吗？步进越小，拖到手抖的概率越高。
06亮度的存储要改　现在 NVS 里 brt 是 0–4 五档。改成连续后要存 20–100，老值要线性映射一次。这是个格式变更，我要先写迁移测试再动代码。
07「亮度保护」就是按时间的　设备没有光线传感器，实际逻辑是 23:00–07:00 把 AOD 表盘封顶到某一档。名字已按你的叫法改成「亮度保护」，值那一列还是「暗一档 / 暗两档 / 跟随亮度」，要换成别的说法吗？
08行高与字号　现在定 48 / 16，一屏 8 行。想更松 52 / 16（多 0.3 屏滚动），想更紧 44 / 14。
09展开时要不要收起别的行　我定的是收（同时只开一行）。滑块行展开后不自动收，要点标题才收 —— 这样连着调不会被打断。
